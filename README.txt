HONA — VERSÃO PORTÁTIL

Arquivos principais:
- index.html: estrutura completa do site.
- styles.css: identidade visual, responsividade e animações.
- script.js: navegação suave e comportamento das perguntas frequentes.
- assets/: logos, monogramas e imagens utilizadas.

Como usar:
1. Mantenha todos os arquivos e a pasta assets juntos.
2. Abra index.html no navegador para visualizar.
3. Para publicar, envie a pasta inteira para a ferramenta ou hospedagem escolhida.
4. Para adicionar pagamentos, substitua o href dos botões pelos links públicos do Mercado Pago.

Esta versão não depende de React, Next.js, Node.js ou do ChatGPT Sites.
